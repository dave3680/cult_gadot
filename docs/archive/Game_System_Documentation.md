## Actual Scene Flow (Code)
Start flow:
1. `MainMenu`
2. `DoctrineSelect`
3. `RunGame`

Week clear flow (weeks 1..9):
1. `RunGame` (week cleared)
2. `Breeding`
3. `Shop`
4. `NestSelect`
5. `RunGame` (next week)

Terminal states:
- Final clear (`current_week >= max_weeks`) -> `Victory`
- Week fail after round 2 -> `GameOver`

## Core Systems
- Global state and run lifecycle:
  - `reset_run`, `start_week`, `init_starting_pool`
- Combat scoring pipeline:
  - `_score_selected_internal`
  - additive + multiplier + trait/relic/doctrine hooks
- Trait system:
  - 15 common, 15 rare, 5 legendary base traits
- Combo trait system:
  - generated by `scripts/ComboTraitGenerator.gd`
  - loaded/indexed in `GameState`
- Relic system:
  - 50 relics
  - phase hook registry (`PRE_ADD`, `PRE_MULT`, `MULTIPLIER_ADJUST`, `POST_RESOLVE`)
- Breeding:
  - explicit nests + wild breeding both active
  - nest rarity resolution + combo preference + parent trait interactions
- Shop:
  - rarity rolls, relic buy/reroll, recruits, ritual offers, pool actions, relic pack
- Simulation/test harness:
  - balance sim bands, CSV + text report output

## Economy and Shop Rules (Current)
- Relic costs:
  - `COMMON=10`, `UNCOMMON=20`, `RARE=30`, `LEGENDARY=40`
  - `Tithe Discount` reduces cost by 1 (min 2)
- Rerolls:
  - one relic reroll per shop (`shop_rerolls_used >= 1` blocks further)
  - first reroll can be free via `Sharpened Chalk` or `Clean Hands` carryover
- Recruits:
  - base 3 offers, or 4 with `Blood Market Stall`
- Relic pack:
  - sacrifice 10 pool followers for 2 relic choices

## Breeding and Nesting (Current)
- Nest system:
  - fixed nest count from `STARTING_NESTS` (currently 2)
  - nested followers are excluded from hand draw
- Post-clear breeding:
  - `resolve_nest_breeding` then `resolve_wild_breeding`
- Trait inheritance/rarity:
  - rarity-aware nest targeting, combo trait lookup by parent pair
  - relic/trait overrides (`Seal of Inheritance`, `lineage_tutor`, `chosen_veil`, `apostolic_womb`, apostle)

## Phase 0 Status (2026-02-26)
Implemented in code:
1. Overflow conversion is centralized in `GameState.apply_overflow_blood_for_target(...)` and reused by runtime and sim.
2. Overflow cap is now applied from config.
3. Director's Cut now supports true +/-15% rerolls (rounded to nearest 5).
4. Shop relic buy signals are connected once in `_ready` (no rerender reconnect).
5. Favored breeders are integrated:
- pool actions enabled when `Selective Breeding Scroll` is owned
- favored pair is prioritized and boosted in wild breeding
- favored parents improve nest rarity-up odds.
6. Simulation determinism improved:
- deterministic per-run seeds
- deterministic shuffle helpers replacing global `shuffle()` in sim-critical paths.

Known remaining cleanup:
